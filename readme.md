# Mushroom Yield Forecast

A machine learning project for polyhouse sensor data and yield prediction.

---

## Environment Setup & Verification

### 1. Activate the Virtual Environment

Before running any scripts, ensure your virtual environment is active.

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

## 2. Folder Map

```text
mushroom-yield-forecast/
├── data/
│   └── raw/          # Raw polyhouse sensor data
├── models/           # Trained machine learning model artifacts
├── notebooks/        # Data exploration and prototyping
├── src/              # Source code and scripts
│   └── smoke_test.py # Environment verification script
├── .gitignore        # Files ignored by Git (e.g., venv/)
├── README.md         # Project overview and instructions
└── requirements.txt  # Project dependencies
```
